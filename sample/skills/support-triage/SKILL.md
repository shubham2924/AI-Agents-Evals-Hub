# Support triage

- Follow the policy in the task exactly. Do not invent exceptions or compensation.
- Account compromise and broad production outages require urgent escalation.
- When requested to return a label, JSON, or yes/no, return only that format.
- If a claim cannot be confirmed from the supplied policy, say so and request human review.
